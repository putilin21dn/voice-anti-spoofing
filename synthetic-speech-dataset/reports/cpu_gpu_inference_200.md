# Spectra-0: CPU и GPU на 200 звонках

Одни и те же 200 звонков бинарной когорты 11–12 и 16 ноября. Состав по дате, классу и длине речи пропорционален когорте, внутри группы берутся первые `call_id`. Порог прежний: synthetic, если средний margin ниже 0.22710928916931153. Окно — 4037 мс речи. Считается по одному окну, как в живом звонке, без пакета окон.

GPU: NVIDIA GeForce RTX 5060 Ti. CPU — 1 и 4 потока PyTorch. Время окна включает preemphasis, перенос тензора и forward со softmax. Два прогрева до первого звонка в цифры не входят.

SVM и LightGBM в этом сравнении нет: они и так считаются на CPU, отдельного GPU-пути у них нет.

## CPU против GPU на том же звонке

Медиана окна на 1 потоке CPU больше медианы GPU в 52.4 раза. Класс CPU и GPU разошёлся у 0 из 200. Максимальная разница средних margin CPU и GPU — 0.0060.

Перенос на GPU по звонкам: медиана 0.177 мс, forward 26.7 мс. На CPU почти всё время окна — сам forward.

Подготовка wav и VAD в это время окна не входит. Её медиана на CPU, 1 поток — 10.6 мс, на GPU — 15.6 мс. Это один проход на звонок.

Окно речи длится 4037 мс. p95 всех трёх устройств ниже 4037 мс, одно окно успевает досчитаться до прихода следующего. Четыре потока PyTorch — это один звонок на четырёх ядрах, не четыре звонка сразу. Замер одного процесса на этой машине, не время сервера воркера.

Разница с сохранённым margin меньше расстояния до порога у: CPU, 1 поток, CPU, 4 потока, GPU.
