# scripts

Команды из корня репозитория:

- `python scripts/check_setup.py` — что уже есть локально, без печати секретов
- `python scripts/bootstrap.py` — venv трёх компонентов, установка requirements, тесты
- `python scripts/run_tests.py` — те же тесты ещё раз

Spectra, скачивание звонков и прогон ансамбля A этими скриптами не запускаются.
