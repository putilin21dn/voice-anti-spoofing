# 0001. Компоненты остаются соседними каталогами

## Решение

Четыре проекта лежат в корне `voice-anti-spoofing` под исходными именами. Они не переименованы и не вложены в общий `src/`.

## Почему

Импорты `src.*` и относительные пути `../<имя-репозитория>` уже завязаны на эту раскладку. Перенос в `src/dataset_collector` и аналоги сломал бы запуск без правки кода. Правка путей не нужна для организации репозитория и меняла бы рабочий механизм запуска.

## Следствие

Корневые `configs/`, `scripts/`, `tests/` и `tools/` только объясняют, где лежат настоящие конфиги, команды и тесты. Дубликатов кода в них нет.
